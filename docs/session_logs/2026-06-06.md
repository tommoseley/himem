## CloudKit schema V2 + retry-on-failure (commits eed9c57, e725026)

### eed9c57 — V1 → V2 bump
- `schemaInitializedV1` key bumped to `schemaInitializedV2`.
- Forces already-installed Debug builds to re-run `initializeCloudKitSchema` so the V2 schema (AssistBalance removal, OrganizePass.nextStepsMarkdown removal, ProcessingTask removed from Cloud config) publishes to Development.

### e725026 — Don't burn the flag on failure
- Symptom risk: `try?` swallowed schema-init errors but still set the V2 flag, preventing retry next launch.
- Fix: `do { try cloudKitContainer.initializeCloudKitSchema(options: []); UserDefaults.set(true, forKey: schemaInitKey); NSLog("… succeeded …") } catch { NSLog("… FAILED: \(error) — will retry next launch") }`. Flag only set on actual success.
