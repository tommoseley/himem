Anatomy

  1. 1
    Greeting — small, secondary. Time-aware (Good morning / afternoon / evening). The ochre dot is a tiny "you're seen" beat. 9pt margin from status bar.
  2. 2
    Wordmark — Source Serif 4, 64pt, ink. The italic Mem in ochre is the only colored character. Anchor of the screen.
  3. 3
    Daily moment — italic serif epigraph + small caps attribution. Pulled from a curated list, rotates daily. Quiet. Not a feature.
  4. 4
    Cloud handshake — honest status. "Syncing your bin · iCloud" → "Ready" → fade to feed. If offline: 'Offline · showing local entries'.
  5. 5
    Progress hairline — 2pt. Eases to 100% when CloudKit is ready. Never indeterminate. If it'd take >3s, hand off to feed and surface progress as a pill there.

Choreography

~1500ms total. Greeting 0ms. Wordmark 80ms. Moment 220ms. Progress 360ms. Footer 520ms. Hand off when CloudKit reports ready, not on a fixed timer.

What this is not

Not a splash. Not a full-screen logo lockup. It's a real screen doing real work — the brand beat is a side effect of being honest about cold-start latency.

States we cover

Cold start — full sequence. Warm start — skip; go straight to feed. Offline — moment + "Offline · local only" footer. First run — onboarding takes over.

What earns the seconds

Real work (CloudKit), real warmth (greeting + epigraph), real identity (wordmark). No spinner-for-spinner's-sake. If we ever shorten cold start, we shorten this in lockstep.
