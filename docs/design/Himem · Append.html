Himem · iOS · Append (FAB → floating actions)

Adding to a memory.

The detail screen is a timeline of contributions. To add to it, the user taps the FAB and a small stack of action pills rises directly above it. They pick one; the corresponding capture flow opens; the new entry lands at the bottom of the list. No sheet, no modal title, no Done button — the list is the surface, the FAB is the entry, the pills are the picker. This page is the spec for Claude Code: states, geometry, motion, and copy.

Closed · Open

Two states. Closed = list + FAB. Open = scrim + action stack + rotated FAB. The detail content stays mounted underneath in both states.

States & transitions
01 · Rest FAB visible, list scrollable FAB anchored bottom-right, ochre fill, +. List scrolls under it; FAB does not move.
02 · Tap FAB Open the stack Scrim fades in over the list (180ms). FAB rotates 45° + tints to #8C2F0E (220ms spring). Action pills enter staggered (see motion).
03 · Tap a pill Dismiss + open capture Stack collapses (140ms ease-out). FAB rotates back. Capture flow for that modality opens (existing screens — voice recorder, camera, note editor, etc.).
04 · Tap scrim (or FAB) Dismiss without picking Same collapse animation. List fully visible again.
05 · Capture finishes New entry appended Entry inserts at the bottom of the timeline with a brief fade-in (200ms). List auto-scrolls to keep it in view.
06 · Capture cancelled Return to detail No mutation. List exactly as it was.
Motion · stagger

Pill enter sequence (open)

On tap, pills rise from behind the FAB and fade in. Voice (closest to FAB) leads; the rest follow at 30ms intervals. Each pill animates 180ms with cubic-bezier(.16,1,.3,1). Translate from +12pt Y + opacity 0 → settle. On dismiss, reverse but compressed to 120ms with no stagger.

0ms 120ms 240ms Attach · 120 Note · 60 Voice · 0

(Photo and Video lanes omitted for clarity — they sit between Note and Attach at 30ms / 90ms.) FAB rotation runs in parallel with the first pill, not after.

Implementation notes

  1. Single source of truth. The same component handles both append (inside an existing memory) and capture-new (FAB on Today). For capture-new the result creates a new memory whose first entry is the captured contribution.
  2. Handedness setting. A single switch in Settings flips the FAB anchor from right: 22pt to left: 22pt and right-aligns the action stack to the left edge instead. No layout fork; one alignment token.
  3. Dismiss semantics. Tap scrim, tap rotated FAB, or hardware back all run the same dismiss animation. Pulling the list (still scrollable underneath the scrim? no — list is locked while open) does nothing.
  4. Accessibility. FAB is one button with aria-expanded; opens an action list with role="menu". Each pill is role="menuitem". VoiceOver order: Voice first (matches visual hierarchy and use frequency), then Photo, Video, Note, Attach.
  5. Reduced motion. Honor prefers-reduced-motion: FAB rotation snaps; pills fade in together over 100ms with no Y translate.
  6. Z-stack. Bottom→top: timeline · scrim · action stack · FAB. The FAB sits above the stack so its rotation reads cleanly and the “X” is unambiguously the dismiss control.
  7. Don’t reuse the Contribute sheet. The medium-detent “Contribute” modal we sketched earlier is retired in favor of this pattern. Delete it from the detail flow.
