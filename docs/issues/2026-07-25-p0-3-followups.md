## 1. `createMemoryFromVoiceClips` + `appendClips` are now production-dead — remove

**Type:** dead-code cleanup.

Piece C rewired the two bench-placement callers (`CreateMemoryFromClipsSheet.createMemory` → `createMemoryFromExistingClips`; `.appendToExistingMemory` → `attachExistingClips`) and deleted the two lifecycle promoters (`placeInboxClip` / `createMemoryFromInboxClip`) that were the only other callers. `EntryLifecycleService.createMemoryFromVoiceClips` and `.appendClips` now have **zero production callers** — only test coverage.

**Remove in a follow-up**, together with their money-test files:
- `CreateMemoryFromClipsAssemblyTests` (tests `createMemoryFromVoiceClips` — the orphan-`.note` guard; moot once the primitive is gone).
- `EntryLifecycleServiceAppendClipsTests` (tests `appendClips`).

Not done now because deleting tested primitives + their guards is a separate, reviewable change, not part of the P0-3 behavior.

## 2. `ClipDetailView` is dead — remove

**Type:** dead-code cleanup.

`ClipDetailView` (both `.managed` and `.inbox` `Source` paths) has **no constructors anywhere** in the app — it was superseded by `ClipEditorModal` (the boxed ✎ Edit, per `Clip model · spec.md`). Its `.inbox` write path (`recordTranscriptionAttempt` / `InboxManifest.recycleClip`) is therefore unreachable, which is why the P0-3 write-path sweep did not need to touch it. Remove the file in a follow-up.

## 3. `ExistingMentionsRefinementTests` — `processEntry` sends an empty existing-mentions list (own bug-first cycle)

**Type:** correctness bug — **pre-existing, NOT introduced by P0-3.**

Two tests fail deterministically on `main`/the branch and reproduce identically on the A-only state (which touches no `ProcessingEngine` code), so this is not P0-3 fallout:
- `processEntry_sendsExistingMentionValuesToAnalyzer` — expects `["Bob","John","Sausage making process"]`, gets `[]`.
- `processEntry_existingMentions_dedupedCaseInsensitively` — expects count `1`, gets `0`.

`ProcessingEngine.processEntry` is sending the analyzer an **empty** existing-mentions list when the entry already has `.person`/`.project`/`.idea` entities. Needs its own **bug-first** cycle: reproduce → verify the failing test fails for the right reason → fix the gathering → verify. Out of P0-3 scope.

**Note on suite hygiene (observed, not fixed):** `ThumbnailServiceDedupTests` and `DebouncedTriggerTests.spacedFires` flake under parallel execution (shared `ThumbnailService.shared` singleton / timing) — both pass in isolation. Candidates for `@Suite(.serialized)` per CLAUDE.md §Test Concurrency.
